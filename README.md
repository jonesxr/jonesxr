# Moro! Olen Jouni 👋

Olen sulautettujen järjestelmien ja elektroniikan opiskelija @TAMK. Rakentelen mielelläni älykkäitä laitteita, mikrokontrollereita ja erilaisia IoT-ratkaisuja.

### 🛠 Mitä teen

- **Laitteisto:** ESP32, Arduino ja sensorit 🔌
- **Ohjelmisto:** C++, Python ja PlatformIO 💻
- **Kiinnostuksen kohteet:** Robotiikka ja automaatio

Tykkään keskittyä tekemään laitteista älykkäämpiä ja rakentamaan ratkaisuja, jotka ovat sekä käytännöllisiä että luotettavia.
